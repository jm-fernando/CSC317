## 🧠 Description of Implementation (Approx. 150 Words)
This project is a simple JavaScript calculator that's built using a combination of HTML, CSS and JavaScript functionalities. It allows users to perform basic mathematical functions (addition, subtraction, multiplication and division). It also performs percantage conversion and allows decimal input. The layout closely resembles the Calculator app found on iPhones and it's color scheme with a dark background with light text for contrast, bronze colored buttons for operators, gray for utilities and dark gray for numbers. The calculator is responsive and also includes a navigation bar with a link directing the user back to the Github Pages.

## ⚙️ Challenges and Solutions
A key challenge was structuring the JavaScript to handle different button types without repetition.  
This was solved by organizing logic blocks for each operator and using `parseFloat()` to manage numeric conversions safely.  
Another challenge was adding keyboard support, which required mapping keypress events to existing button functions while preventing unwanted input overlap.
